## Reporting a vulnerability

취약점은 공개 이슈로 올리지 말고 [CONTACT]으로 알려 주세요.

받은 신고는 [RESPONSE_WINDOW] 안에 접수 확인을 보냅니다. 이 프로젝트는 [SUPPORT_LEVEL] 수준으로 유지되므로, 수정 일정은 확인 후 사안별로 알려 드립니다.

신고에 다음이 있으면 확인이 빨라집니다.

- 영향받는 버전과 실행 환경
- 재현 절차
- 확인된 영향 범위
