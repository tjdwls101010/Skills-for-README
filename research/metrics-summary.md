# 코퍼스 실측 — 계층별 구조 지표

README 73개(5계층)와 초기 고전 12개의 3·9개월 스냅샷 24개를 `repo-showcase`의 지표 모듈로 측정했다. 수집 명세와 선정·제외 기준은 [`corpus-manifest.json`](corpus-manifest.json)에, 원문은 `.tmp/`(gitignored)에 있다.

## 재현

```bash
# 1. 원문 재수집 (corpus-manifest.json의 repo + readme_sha)
gh api repos/<repo>/git/blobs/<readme_sha> --jq .content | base64 -d > .tmp/readmes/<owner>__<name>.md

# 2. 집계
python3 research/aggregate_corpus.py
```

`aggregate_corpus.py`는 스킬의 `showcase.readme_metrics` / `first_screen`을 그대로 부른다. 즉 **여기 있는 숫자와 스킬이 레포에 내리는 판정은 같은 코드에서 나온다.** 지표 정의가 바뀌면 이 표도 함께 바뀌어야 한다.

## 읽어낸 것

**1. 0-스타 레포의 모델은 "지금의 bat"이 아니라 "3개월째의 bat"이다.** 같은 12개 도구가 3개월 203줄 → 9개월 290줄 → 현재 514줄로 자랐고, 설치 헤딩은 20번째 줄에서 74번째 줄로 내려갔다. 지금의 fzf가 설치를 108번째 줄에 두는 것은 인지도 이후에 할 수 있는 배치다. 처음 오는 방문자에게 그 배치를 흉내 내면 아무도 설치까지 내려가지 않는다.

**2. 저관심을 가장 뚜렷하게 가르는 것은 첫 화면의 결과 증거다.** low_traction은 7/20, 초기 고전 m3는 10/12, m9는 12/12, 현재 고전은 16/20이다. 결과 이미지가 아예 없는 비율은 low_traction 16/20 대 고전 m3 1/12로 더 벌어진다. low_traction의 증거는 있어도 대부분 출력 블록 하나(13/20)이고 README 뒤쪽에 있다 — 첫 결과 이미지의 중앙값 줄이 78이다.

**3. 한 줄 정의는 저관심 쪽이 두 배 이상 길다.** 초기 고전 m3의 62자 대 low_traction의 138자. 길이 자체가 문제라기보다, 짧은 정의는 방문자가 아는 것에 자기를 붙이고 긴 정의는 자기 어휘로 자기를 설명한다. **아는 도구·작업을 명시적으로 지목하는 비율은 초기 고전 m3가 4/12, low_traction은 0/20이다.** 다른 어느 계층도 초기 고전만큼 높지 않다(현재 고전 3/20, trendshift 0/21, mega 0/8).

**4. description은 길이가 아니라 잘림이 문제다.** low_traction 중앙값 126자, 8/20이 137자를 넘어 **검색 결과에서 단어 중간이 잘린다**(측정 근거는 [`codex-reviews.md`](codex-reviews.md) 부록). 고전 20개와 mega 8개는 잘리는 것이 하나도 없다. 잘린 레포는 검색에서 자기 정체성의 뒷부분을 잃는다.

**5. 배지는 갈라내지 못한다.** low_traction 중앙값 0개, 인기 계층도 2~4개다. jq는 배지 0개에 35,565 stars, Harness-Creator는 배지 8개·topics 15개에 4 stars다. 커뮤니티 파일도 마찬가지다 — SECURITY는 인기 계층에서도 절반 이하이고, CoC는 1인 프로젝트에 대부분 없다.

**6. 줄수와 설치 헤딩 위치는 가르지 못한다.** low_traction의 줄수(220)는 초기 고전(203)과 거의 같고, 설치 위치(73)는 현재 고전(67)과 비슷하다. **"짧게 써라", "설치를 위로 올려라"는 이 코퍼스가 뒷받침하지 않는다.**

## 한계

전환 데이터가 없다. 별 수는 노출·명성·시간이 섞인 값이고, MSR 종단 연구는 오히려 **인기가 문서 작업을 부른다**는 역방향을 보고한다. 여기서 나온 것은 상관이며, 스킬은 이것을 "이렇게 하면 별이 는다"가 아니라 **"방문자가 문서만으로 판단할 수 있는가"**의 원칙으로 쓴다.

계층 간 시대도 다르다(low_traction은 2026년 생성, 고전은 2012~2023년). classic_solo 현재 20개와 초기 12개는 같은 모집단이 아니므로, 성장 비교는 표의 "같은 12개" 행으로만 해야 한다.
